# Security and responsible use

This repository is an educational guide for a deliberately vulnerable local training application.

## Authorized scope only

- Use Juice Shop only on devices and networks you own or have explicit permission to test.
- Keep the instance on a trusted private network.
- Never expose the service through router port forwarding, public cloud hosting, or a public tunnel.
- Do not use the guide to test unrelated websites, accounts, devices, or networks.
- Use lab-created test accounts and data only.

## Reporting issues in this guide

If you find a mistake in the guide or a script, open an issue in this repository with a concise description and safe reproduction steps. Do not include passwords, session tokens, or personal information.

## Upstream project

OWASP Juice Shop is maintained separately. Report upstream application issues using the reporting instructions in the [official repository](https://github.com/juice-shop/juice-shop), not by treating this guide repository as the upstream project.

## No warranty

The notes are educational and provided as-is. Network setups and dependencies vary by device and software version. Always verify commands before running them.
